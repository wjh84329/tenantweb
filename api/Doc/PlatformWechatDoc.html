平台公众号教程

选用使用平台设定的公众号详情教程：

 

登录后台首页，上方导航，账户管理>微信密保
选用平台默认已开通的公众号，选择下列，第一个平台公众号，确定保存，即可使用。
并同时下载，平台配置设定的“GOM、GEE脚本”配置，安装到服务端，必须配置登录器微信密保PAK补丁文件，打包文件一起使用。
其他无需设置，为GM游戏方便简单使用，内附使用说明，请自行查看。
 GOM/GEE脚本：下载安装在传奇服务端里。此脚本支持GOM/GEE，其他引擎脚本可自行参考本脚本修改。
新人微信密保登录：



安装游戏NPC微信密保，在新人地图，也需添加一个，新人登录游戏时，扫码关注微信公众号验证，绑定微信密保，自动传送到新的地图，开始游戏。
脚本默认传送至，土城地图（3）MAP。
