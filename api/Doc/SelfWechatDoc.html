自己公众号教程

微信公众号配置详情教程：

 1、打开微信公众号官网  https://mp.weixin.qq.com/  如果您没有公众号，请先注册，如果只是作为验证功能，不需要主动发送广告信息，服务号或订阅号都可以，也不用认证。

 2、注册登录后，拉到浏览器最下方左侧有个“基本配置”点击后即可获得网关所需要填写的APPID、APPSECRET，如下图:

3、 接下来点击下方的服务器配置，我这里已经配置过所以显示的为“修改配置”，如下图:


 服务器地址（URL）：请直接填写 http://www.7xpay.com/home/WechatEvent2 。
 令牌（TOKEN）： 在平台商户后台配置公众号出生成Token通讯填写上
 消息加解密密锁（ENCODINGAESKEY）：随机生成
 消息加解密方式：明文模式。

4、令牌（TOKEN）获取方式在：在平台商户后台->账户管理->微信密保，选择自己公众号


 这里就是平台生成的随机，通讯Token，填写在公众平台：令牌Token配置 即可。
