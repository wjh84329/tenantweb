充值补发教程

1，手动充值补发：

 

登录后台控制面板，左侧导航， 点击手动充值。
游戏账号：补发账号，一定要输入正确，输错，游戏角色无法领取。
分区：选择补发游戏分区，一定要正确，否则无法领取，或者玩家有多个账号在其他区，都可以领取的到。
充值金额：补发充值多少，补发多少，自己定义。
充值方式：选择补发支付渠道，支付宝，微信，qq钱包，花呗，银联扫码，网银。
关闭赠送：勾选后，补发时，关闭全部附加赠送，激励赠送，装备赠送，积分赠送比例，充值渠道。
额外补发只补发元宝：勾选后，补发时只补发元宝，充值渠道赠送，无其他赠送。
补发原因：任意字母数字

2，查询充值补发记录：

查询时，可选按照分类选择查询，游戏账号，所属分区，补发类型。
查询补发记录，查询后显示手动充值，流水号，游戏分区，充值方式，金额，账号，IP，时间都有明细的详情。

3，整区补发：




登录后台控制面板，左侧导航，整区补发。
整区自动补发，
 分区：选择你要补发的游戏开区版本的分区。
勾选 开启自动整区补发：
自动补发时间： 设置开区之后的时间，自动补发 注意时间不能小于开区的时间。
测试区开放时段：选择开区测试时间段，在这个时间段之内的充值成功订单的玩家，进行补发，每次补发，选择的时间段， 3天之内时间段有效。
额外补发：自行定义补发额外赠送比例。
基础选项手动充值：勾选后补发时会补发，包含手动充值过的订单。
清理未领取玩家账号：勾选时，清理玩家的充值账号文件记录，此操作会重新刷新生成新的充值脚本文件，清空数据。
 预览：设置选项时间段后，点击预览，查看，您选择的时间段里，能补发多少个充值订单的，账号记录详情。

4，开启整区自动补发：


开启整区自动补发，
分区：选择你要补发的游戏分区。
勾选 开启自动整区补发：
自动补发时间： 设置开区之后的时间，自动补发注意时间不能小于开区的时间。
测试区开放时段：选择开区测试时间段，在这个时间段之内的充值成功订单的玩家，进行补发，每次补发，选择的时间段，3天之内时间段有效。
其他选项：额外补发，基础选项包括手动充值，清理未领取的玩家账号，补发原因，同上面一样的操作，不在重复。


补发后：补发任务里，会显示自动倒计时，详情待补发分区名字，时间，赠送的另外比例。


同时：补发任务记录，也会显示，您设定的时间，分区名字，补发额外比例，状态：，待补发：完成记录。
