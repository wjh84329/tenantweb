API接口概述

由于目前市面上自动化工具较多，为了适应友商多元化的接入场景，特意开放公共API以供自动开区工具使用，API接口是其他系统与本系统交互最方便的途径。

API接口请求方式只支持POST。

API接口地址默认为http://newapi.7xpay.com，合作方接入时，建议采用配置方式，避免由于不可变因素引起平台更换接口域名。



UserId说明

获取方式：登录平台 -> 首页头像右侧账号下面。

由于接口权限较高，拥有删除分区、修改分区等功能，所以请保管好UserId，分组、分区等数据丢失后，无法找回。



Sign说明

获取方式：此文档上的所有接口都采取md5签名方式，签名需把所有非空的参数按照ascii 顺序的方式进行key=value&key1=value1拼接，在拼接结果末尾直接拼接上md5 签名密钥。如： key=value&key1=value1&key2=value2&key3=value3&key4=value4{MD5key} 再对此拼接串进行md5加密，加密结果转为小写。例如：attach=pay&charset=UTF-8&bank_code=CMB&notify_url=http://www.xxx.com/notify url&order_id=202006011536001&pay_type=1&pro_code=1001&return_url=http://ww w.xxx.com/returnurl&total_fee=100&user_id=100113832ab0a87fee83ceb566924afe4fb6，签名为：23ccb20d525b8e3bd502ca0abee827c2

签名是用于接口交互中的数据防篡改验证机制。
