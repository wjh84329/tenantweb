# Tenantweb UI Redesign Reference

Use `tenantweb-ui-redesign-reference.png` as the visual baseline for the upcoming UI rewrite.

Core direction:
- Modern merchant admin dashboard, not a marketing page.
- Dark graphite left control panel with compact navigation.
- Warm off-white content background.
- Dense but organized SaaS layout.
- Emerald and amber accents, with restrained blue only for links and active states.
- Low shadows, subtle borders, flat surfaces.
- Card and button radius should stay at 8px or less.
- Preserve existing features and bindings; only change layout and visual presentation.

Functional areas to keep:
- Top main navigation.
- Left control panel.
- User/account profile area.
- Balance, withdrawal, recharge and income stats.
- Announcement carousel/ticker.
- Function settings with switches, radio groups and action buttons.
- Latest recharge order table.
- Gateway download overlay.
- Right floating quick action dock.
