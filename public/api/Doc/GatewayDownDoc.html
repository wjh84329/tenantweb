网关下载教程

1，网关下载：


登录后台控制面板，左侧导航，下载网关>点击热血传奇图标，选项（传奇世界）也一样。

 
下载好的网关放入服务器，通讯，接口秘钥一致，端口，需自行修改保存，启动即可。

2，配置网关秘钥：




登录后台>账户管理>通讯秘钥：
点击按钮可随机生成通讯秘钥，APIKEY秘钥，与服务器上网关对接一致，即可正常通讯。
