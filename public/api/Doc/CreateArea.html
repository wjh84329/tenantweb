创建新分区

应用场景

该接口可供第三方自动开区工具等，创建一个新的分区。

一个分区只能拥有一个比例模版，但是可以拥有多个分组

接口链接

请求方式：只支持POST

URL地址：http://newapi.7xpay.com/Api/CreateGameArea

请求参数

字段名 变量名 必填 类型 示例值 描述
账户userId userId 是 Int 1024 充值平台分配给商户的userId，4位长度，是调用api的基本凭证
分区名称 partitionName 是 String 热血传说四区（编码后：%E7%83%AD%E8%A1%80%E4%BC%A0%E8%AF%B4%E5%9B%9B%E5%8C%BA） 分区名称，50个字符或汉字以内，使用UrlEncode(UTF-8)编码，可参考编码/解码工具
服务器IP serverIp 是 String 111.2.3.4 该分区所在的服务器IP
充值网关端口 serverPort 是 Int 7788 服务器上运行的充值网关的端口
分区路径 serverPath 是 String D:\MirServer(编码后：D%3A%5CMirServer) 该分区所对应的服务端目录路径，使用UrlEncode(UTF-8)编码，可参考编码/解码工具
模版ID modelId 是 Int 234 模版的唯一标识ID
分组ID集合 groupIds 是 String 123,234,345 分组ID集合，多个分组ID间用小写逗号隔开
充值方式 payType 否 int 1 2-网页扫码，0-游戏内扫码，1-以上两者，默认为网页扫码
是否开启元宝蛋 isOpenYbd 否 Int 2 是否开启元宝蛋功能，1为是，2为否，不传该字段时默认值为2
签名 sign 是 String d94a1202d575b1735191a4aff4ad133ea4a4c1b8 把所有非空的参数按照ascii 顺序的方式进行key=value&key1=value1拼接，在拼接结果末尾直接拼接上md5 签名密钥（详见：概述）

举例如下：

http://newapi.7xpay.com/Api/CreateGameArea?userId=1024&partitionName=%E7%83%AD%E8%A1%80%E4%BC%A0%E8%AF%B4%E5%9B%9B%E5%8C%BA&serverIp=111.2.3.4&serverPort=8899&serverPath=D%3A%5CMirServer&modelId=1234&groupIds=234,345,456&isOpenYbd=2&showTime=20180101133000&isAutoUpdate=1&autoUpdateTime=20180101133000&autoUpdateName=%E7%83%AD%E8%A1%80%E4%BC%A0%E8%AF%B4%E4%B8%80%E5%8C%BA%E6%AD%A3%E5%BC%8F%E5%BC%80%E6%94%BE&sign=d94a1202d575b1735191a4aff4ad133ea4a4c1b8

返回结果

字段名 变量名 必填 类型 示例值 描述
业务状态 result 是 Boolean true

true/false

此字段是业务标识状态，true代表业务处理成功，并成功返回

业务状态描述 message 是 String 成功

当result为false时返回信息为错误原因 ，例如

商户不存在

数据集 Data 否 String 无

当result为true时，数据会装入该字段一并返回

Data内的id字段 gameid 是 Int 12345

分区创建成功后，该分区的唯一id

举例如下：

{
    "result": true,
    "message": "分区创建成功，网关通讯失败，网关服务器连接失败",
    "Data": {
        "gameid": 12345
    }
}

状态

状态 描述
true 成功
false 错误，具体错误信息请参照message字段
