订单支付

应用场景

该接口可供第三方自动开区工具等，进行订单支付。

签名规则

订单签名不是按字典序排序，而是按固定顺序直接拼接，再追加 |商户密钥 后计算 MD5 并转成 32 位大写。

1. 提交请求 Sign 生成规则

  1. 按顺序拼接：Version + MerId + TransNo + OrderAmount + PayChannel + PostBackUrl + Remark
  2. 在末尾追加：|SignKey（通讯秘钥）
  3. 对最终字符串做 MD5，并转成 32 位大写
Sign = MD5(Version + MerId + TransNo + OrderAmount + PayChannel + PostBackUrl + Remark + "|" + SignKey).ToUpper()

2. 下单同步返回 Sign 规则（当前接口返回 JSON 使用）

  1. 按顺序拼接：Version + MerId + TransNo + OrderAmount + PayChannel + Remark + TrxNo + Status + TransTime
  2. 在末尾追加：|SecretKey（商户密钥）
  3. 对最终字符串做 MD5，并转成 32 位大写
Sign = MD5(Version + MerId + TransNo + OrderAmount + PayChannel + Remark + TrxNo + Status + TransTime + "|" + SecretKey).ToUpper()

3. 异步通知 Sign 验签规则

  1. 按顺序拼接：Version + MerId + TransNo + OrderAmount + PayChannel + Remark + TrxNo + Status + TransTime
  2. 在末尾追加：|SignKey（通讯秘钥）
  3. 对最终字符串做 MD5，并转成 32 位大写
Sign = MD5(Version + MerId + TransNo + OrderAmount + PayChannel + Remark + TrxNo + Status + TransTime + "|" + SignKey).ToUpper()

注意：PayAmount、Msg、QrCode、ProductName、NotifyUrl 都不参与返回验签。

接口链接

请求方式：支持GET和POST

URL地址：http://newapi.7xpay.com/api/Cashier/Index

请求参数

字段名 变量名 必填 类型 示例值 描述
版本 Version 是 String 1.0 协议版本，例如："1.0"
字符集 Charset 否 string utf-8 字符集（示例：utf-8）
商户标识 MerId 是 String xxxx 平台分配
商户订单号 TransNo 是 String xxxx 最大 50 字符
商品/游戏名称 ProductName 是 string XX充值 商品/游戏名称
充值金额 OrderAmount 是 string 100.00 金额字符串，例如 "100.00"
支付渠道 PayChannel 是 string alipay 支付渠道，如 alipay / wechat
玩家账号/标识 UserInfo 是 String abcd1234 玩家账号/标识
异步通知地址 PostBackUrl 是 String http%3a%2f%2fwww.xxx.com%2fxxx%2fxxx 服务端异步通知地址（平台支付结果会回调该地址）
前端回跳/展示地址 NotifyUrl 否 String http%3a%2f%2fwww.xxx.com%2fxxx%2fxxx 前端回跳/展示地址（可选）
扩展字段 Remark 否 String 123 扩展字段，平台会在返回中原样返回
联系方式 Contact 否 String 12300000000 联系方式
请求签名 Sign 是 String A1B2C3D4E5F6... 请求签名（MD5 32 位大写），用于平台校验请求来源
支付方式 Type 否 Int 0 1为手机支付，0为网页支付；不传时默认按0处理。返回字段中的qrCode，如果是手机端返回二维码源，如果是网页返回收银台地址
玩家充值IP4地址 PlayerIp 否 string 8.8.8.8 玩家充值真实外网地址；不传时平台会优先从请求头和连接信息中自动识别
充值产品编号 Mark 否 string wechat1 如果指定产品，则使用指定产品发起支付

请求签名示例： 

MD5("1.0merchant-uuid-123EXT20251029001100.00alipayhttps://third.example.com/pay-notify123|your_sign_key").ToUpper()

举例如下：

http://newapi.7xpay.com/api/Cashier/Index?Version=1.0&MerId=merchant-uuid-123&TransNo=EXT20251029001&ProductName=充值100元&OrderAmount=100.00&PayChannel=alipay&UserInfo=player123&PostBackUrl=https%3A%2F%2Fthird.example.com%2Fpay-notify&NotifyUrl=https%3A%2F%2Fthird.example.com%2Fpay-return&Remark=123&Sign=A1B2C3D4E5F6...&Type=0&PlayerIp=8.8.8.8

下单同步返回字段说明

字段名 变量名 必回 类型 示例值 说明
版本 Version 是 string 1.0 协议版本
商户标识 MerId 是 string merchant-uuid-123 平台分配的商户编号
商品/游戏名称 ProductName 是 string 充值100元 原样返回
商户订单号 TransNo 是 string EXT20251029001 调用方上送的订单号
订单金额 OrderAmount 是 string 100.00 请求原始金额
实际支付金额 PayAmount 是 string 100.00 平台最终下单金额；如启用随机金额，可能与 OrderAmount 不同
支付渠道 PayChannel 是 string alipay 支付渠道标识
异步通知地址 PostBackUrl 否 string https://third.example.com/pay-notify 原样回显
扩展字段 Remark 否 string 123 原样返回
平台订单号 TrxNo 是 string B26061812345678901 平台生成的订单号（用于对账）
支付状态 Status 是 string 1 1=成功，0=失败
状态说明 Msg 否 string Success 成功时通常为 Success，失败时返回错误说明
二维码/跳转地址 QrCode 否 string https://pay.example.com/qrcode?data=... 创建订单成功时返回；Type=1 时通常返回二维码源，Type=0 时通常返回收银台地址
返回时间 TransTime 是 string 20250308123045 格式 yyyyMMddHHmmss，由平台生成
签名 Sign 是 string 3A1B2C...（32位大写） MD5签名；当前同步返回按上方“下单同步返回 Sign 规则”使用 SecretKey 生成

异步通知说明

支付成功后，平台会以 GET 方式回调商户提交的 PostBackUrl，并把通知参数拼接到 URL Query 中。

商户处理成功后请直接返回包含 OK 的文本（例如 OK），否则平台会继续重试。当前重试间隔约 3 秒。

字段名 变量名 必回 类型 示例值 说明
版本 Version 是 string 1.0 协议版本
商户标识 MerId 是 string merchant-uuid-123 平台分配的商户编号
商户订单号 TransNo 是 string EXT20251029001 调用方上送的订单号
订单金额 OrderAmount 是 string 100.00 请求原始金额
实际支付金额 PayAmount 是 string 100.00 平台最终支付金额；此字段不参与验签
支付渠道 PayChannel 是 string alipay 支付渠道标识
平台订单号 TrxNo 是 string B26061812345678901 平台生成的订单号（用于对账）
支付状态 Status 是 string 1 1=成功，其他值按失败处理
扩展字段 Remark 否 string 123 原样返回
支付时间 TransTime 是 string 20250308123045 格式 yyyyMMddHHmmss
签名 Sign 是 string 3A1B2C...（32位大写） 按上方“异步通知 Sign 验签规则”使用 SignKey 校验

异步通知示例 

GET https://third.example.com/pay-notify?Version=1.0&MerId=merchant-uuid-123&TransNo=EXT20251029001&OrderAmount=100.00&PayAmount=100.00&PayChannel=alipay&TrxNo=B26061812345678901&Status=1&Remark=123&TransTime=20250308123045&Sign=A1B2C3D4E5F6...

商户处理成功后返回：

OK
