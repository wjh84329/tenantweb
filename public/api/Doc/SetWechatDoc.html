公众号配置教程

平台自己公众号配置详情教程：

 1、登录后台首页，上方导航， 账户管理>微信密保

账户管理>微信密保，选项第二个，自己公众号

公众号类型：说明:

订阅号：用于普通推送消息，验证码获取

服务号：用于设定消息关键词菜单回复，验证码获取。

认证服务号： 绑定微信平台登录，消息关键词菜单回复，验证码获取。

公众号的Appid，AppSecret，原始ID，Token，公众平台的开发者中心配置项获取：

公众号Appid：这里填写AppID，在公众平台上的（开发者中心），开发者应用ID

公众号AppSecret：这里填写AppSecret，在公众平台上的（开发者中心），开发者应用密钥

公众号原始ID：这里填写公众号原始ID，是注册公众号账号原始ID

通讯Token：这里的通讯Token，是平台随机生成之后，对接在微信公众号上，找到公众平台（开发者中心）服务器配置下列中的：令牌（Token）填写即可。

被关注回复：自定义随意回复，这里是微信扫码用户关注后，自动回复消息

GOM、GEE脚本下载：安装到传奇服务端游戏NPC，2个地地图，默认新人接待，土城地图，其他地图自行修改， 此脚本文件，用于扫码绑定微信回复验证码，新人微信密保登陆。

GOM、GEE脚本下载：安装到传奇服务端游戏NPC，2个地地图，默认新人接待，土城地图，其他地图自行修改， 此脚本文件，用于扫码绑定微信回复验证码，新人微信密保登陆。

 2、公众号菜单设置

 这里是公众号菜单选项，用户关注可以点击菜单，获取验证码回复，查看。

 菜单上有3个配置，同时分为3个（验证码，文字，跳转链接网址）回复选择菜单。

配置介绍： 只支持设置一级菜单，并且只能设置“跳转链接”、“回复文字”两种类型

提示： 菜单名全部不填，则为删除所有菜单，因微信自身缓存，保存菜单数据后，需等待几分钟，公众号菜单才会变化。
