比例模板教程

1，创建分区比例模板：


  


登录后台控制面板，左侧导航，比例模板>热血传奇，选项（传奇世界）也一样。

 
模板名称：创建分区比例模板名字，对应好自己的版本，便于区分是什么开区版本比例模板。
游戏币名称：
脚本命令：GAMEGOLD +
脚本命令，游戏变量数据指令，懂的编用的脚本技术员，可以自行修改变量使用，新人默认为系统变量就好。

2，附加赠送，积分设置：


附加赠送：
打开勾选，开启状态。
变量名称：
金刚石：GAMEDIAMOND +
荣誉点：GAMEGLORY +
游戏点：GAMEPOINT +
灵符：GAMEGIRD +
声望：CREDITPOINT +
脚本命令：引擎默认变量，根据自己版本需求，自行修改，或删除。
赠送比例：根据需要版本自行修改。

注意：如一些引擎不支持的变量数据，加载会报错，删除即可。

积分设置 ： 打开勾选，开启状态。
积分变量名称：（积分，存款，排名）
 积分文件路径：
积分： ..\QuestDiary\充值积分\积分Save.txt
 存款：..\QuestDiary\充值积分\存款Save.txt
排名： ..\QuestDiary\充值积分\排名Save.txt
 赠送比例：积分名称，积分文件，脚本变量数据路径地址，根据版本需求自行添加，修改变量，或删除。
计算方式：多个选项配置计算方式，充值游戏领取金额不同。

3，装备赠送，激励赠送：



装备赠送：格式写法，根据需求设置充值多少赠送装备。
激励赠送：根据设置充值多少，赠送多少金额。

4，充值渠道默然赠送：



充值渠道：记得勾选开启。
一键设置：开启百分比% 设置，手动任意一个比比例值，一键更改所有，%百分比。

5，多充多送选项：



多充多送：是可以自定义，充值满多少，送多少。
列如：满充值1000元赠送40% ，就是多送40%的元宝数量，不是累计充值到1000元，而是一次性充值满1000元赠送金额。

支付宝，微信，qq钱包，花呗，银联扫码，网银：充值的渠道，根据自己的需求来随意设置。
