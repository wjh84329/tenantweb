获取订单状态

应用场景

该接口可供第三方自动开区工具等，获取账户下的支付通道。

接口链接

请求方式：只支持POST

URL地址：http://newapi.7xpay.com/Api/QueryOrder

请求参数

字段名 变量名 必填 类型 示例值 描述
账户ID userId 是 Int 1024 充值平台分配给商户的userId，4位长度，是调用api的基本凭证
订单号 orderNo 是 String LP202500543641 订单的唯一性标识
签名 sign 是 String d94a1202d575b1735191a4aff4ad133ea4a4c1b8 把所有非空的参数按照ascii 顺序的方式进行key=value&key1=value1拼接，在拼接结果末尾直接拼接上md5 签名密钥（详见：概述）

举例如下：

http://newapi.7xpay.com/Api/GetPayChannel?userId=1024&orderNo=LP202500543641&sign=d94a1202d575b1735191a4aff4ad133ea4a4c1b8

返回结果

字段名 变量名 必填 类型 示例值 描述
业务状态 result 是 Boolean true

true/false

此字段是业务标识状态，true代表业务处理成功，并成功返回

业务状态描述 message 是 String 成功

当result非true时返回信息为错误原因 ，例如

商户不存在

数据集 Data 否 String 无

当result为true时，数据会装入该字段一并返回，格式为Json格式

Data内的数据字段解释

字段名 变量名 必填 类型 示例值 描述
商户Id UserId 是 Int 952 商户的唯一标识ID
订单号 OrderNo 是 String LP202500543641 订单的唯一性标识
订单状态 OrderState 是 Int 1 订单支付状态.0=失败，1＝成功，2＝待支付

举例如下：

{
    "result": true,
    "message": "成功",
    "Data": {
            "UserId": 1024,
            "OrderNo": "LP202500543641",
            "OrderState": 1
    },
}

状态

状态 描述
true 成功
false 错误，具体错误信息请参照message字段
